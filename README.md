# Window Designs

A web application for browsing and purchasing window systems and accessories, built with **Django**.

## Features

- Product catalog
- Categories
- Product details
- Multiple product images
- Shopping cart
- Order management
- Stripe payment integration
- REST API
- JWT authentication
- Django Admin

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- HTML
- CSS
- Bootstrap
- JavaScript
- Stripe API

## Installation

```bash
git clone https://github.com/Randysman/widnowdesigns.git
cd widnowdesigns

python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Visit **http://127.0.0.1:8000/**
